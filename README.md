# Лабораторная работа: Архитектуры автокодировщиков для восстановления и анализа изображений

## 🎯 Цель работы
Изучить принципы построения, обучения и применения автокодировщиков (Autoencoder) для решения задач восстановления изображений, снижения размерности и обнаружения аномалий. Реализовать различные архитектуры (сверточные, полносвязные, с двумерным латентным пространством), освоить методы визуализации скрытых представлений и оценить качество реконструкции с использованием метрики MSE.

---

## 🛠 Технологический стек
- **Framework:** TensorFlow 2.x (Keras), PyTorch 2.x
- **Data Processing:** NumPy, scikit-learn
- **Visualization:** Matplotlib
- **Dataset:** MNIST (рукописные цифры)

---

## 📊 Структура и задачи исследования

### Задание 1. Автокодировщик с двумерным латентным пространством
Построение автокодировщика, сжимающего изображения 28×28 до двух координат в скрытом пространстве:
- **Данные:** цифры 0, 1, 3 (MNIST)
- **Архитектура:** Dense(256→128→2→128→256→784)
- **Результат:** MSE < 0.034 (достигнуто 0.028)

### Задание 2. Трансформация изображений через автокодировщик
Преобразование любых пятерок в «красивые» пятерки из заранее отобранного набора:
- **Данные:** все пятерки MNIST → целевые красивые пятерки
- **Архитектура:** сверточный автокодировщик
- **Результат:** визуально приемлемое преобразование

### Задание 3. Удаление шума (черные квадраты 8×8)
Автокодировщик для восстановления оригинальных изображений из зашумленных черными квадратами:
- **Размер квадрата:** 8×8 пикселей (случайное расположение)
- **Архитектура:** сверточная (Conv2D + MaxPooling2D + Conv2DTranspose)
- **Результат:** MSE < 0.007 (целевой порог)
